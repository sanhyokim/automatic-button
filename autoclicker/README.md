# 自動クリックアプリ(OCR型)

画面上の指定範囲をキャプチャーカード経由で OCR 監視し、表示されたキーワードに応じて
登録した動作(クリック・数値入力)を自動で実行する Windows 用アプリ。

## 導入方法

1. Python 3.10 以上(Windows 10/11)を用意する。
2. このフォルダーで依存ライブラリを入れる。

   ```
   pip install -r requirements.txt
   ```

   RapidOCR は新しい `rapidocr` パッケージを使う。旧版の `rapidocr_onnxruntime` しか
   入っていない環境でも自動で切り替えて動く(`app/ocr.py` のアダプター)。

3. 起動する。

   ```
   python main.py
   ```

   初回起動時に `config.json` が `main.py` と同じフォルダーに作られる。

4. 単体テスト(必ずこのフォルダーに移動してから実行する)

   ```
   cd <このフォルダー>\autoclicker
   python -m pytest
   ```

   `C:\WINDOWS\system32` など別の場所で実行すると、そのフォルダー全体を探索して
   止まったようになる。

## キャプチャーカードを開けないとき

「キャプチャーカード(機器番号0)を開けません」と出る場合は、次を実行する。

```
python find_capture.py
```

機器番号 0〜9 を順に調べ、開けた番号の解像度を表示し、映っている画面を
`capture_test_<番号>.png` に保存する。自分の画面が映っている番号を、
設定の「詳細」タブの「キャプチャーの機器番号」に入れて保存する。

どの番号でも開けない場合は、次を確認する。
- キャプチャーカードが接続され、デバイスマネージャーに表示されているか
- OBS など、ほかのアプリがキャプチャーカードを使っていないか
- Windowsの設定 → プライバシーとセキュリティ → カメラ で、
  「カメラへのアクセス」と「デスクトップアプリがカメラにアクセスできるようにする」がオンか

## 使い方

1. メインウィンドウ(画面左上)の「設定」を押す。
2. 「共通」タブで
   - キーワード範囲:「範囲を設定」→ 画面をドラッグ。「読み取りテスト」で確認
   - 退避エリア:動作が終わったあとにマウスカーソルを移動させておく場所(クリックはしない)。
     カーソルが文字の上に残るとOCRが読み間違えるため、画面の端など、読み取り範囲とも
     ボタンとも重ならない何もない場所を指定する
   - 待機表示の文字(初期値 `WAITING`)
3. 「ルール」タブで「追加」→ ルール名・キーワード・パターン(A/B/C)と必要な範囲を設定。
   - A: ボタン1をクリック
   - B: 数値範囲を読み取り、入力欄をクリック → Ctrl+A → Delete → 数値を入力 → ボタン1をクリック
     (数値の形式=整数/小数は、メインウィンドウの「数値の形式」で切り替える。全パターンBのルール共通)
   - C: ボタン1 → ボタン2 をクリック
4. パターンBのルールがある場合は、「共通」タブで避難先(A/Cのルール)を選ぶ。
5. 「範囲を表示」で、登録した範囲を3秒間確認できる(緑:読み取り、赤:クリック、青:退避)。
6. 「保存」→「閉じる」→ メインウィンドウの「開始」。
7. 停止は「停止」ボタンか **Escキー**(アプリが前面になくても有効)。
8. 「数値の形式」(整数/小数)は開始・停止ボタンのすぐ下にあり、動作中でも切り替えられる。
   次に数値を読み取るときから反映され、`config.json` にも保存される。

## 構成

```
main.py                  起動(DPI対応、設定の読み込み、GUI)
app/config.py            設定の読み書き・初期値・検証
app/models.py            Region / Rule
app/parser.py            正規化・キーワード照合・数値の形式チェック・数値の確定判定
app/capture.py           キャプチャーの取り込みスレッド
app/ocr.py               RapidOCR アダプター・前処理
app/input_control.py     ベジェ曲線の移動・クリック・入力・中断できる待機
app/hotkey.py            Escキーの監視(pynput)
app/engine.py            状態遷移と動作(ワーカースレッド)
app/gui/                 メイン・設定・ルール編集・範囲設定・範囲表示
tests/                   pytest
```

exe 化(PyInstaller)に備え、`config.json` の場所は `sys.frozen` のときは実行ファイルの
フォルダー、それ以外は `main.py` のフォルダーを基準にしている(`app/config.py` の `app_dir()`)。

## 仕様書にない細部の判断

利用者の操作が少なく、誤動作しない側を選んだ。

### 動作・エンジン

| 項目 | 判断 |
|---|---|
| 開始の準備 | キャプチャーを開く・OCRを準備する間は、状態欄に「開始準備中」と表示する(内部の状態は4つのまま。この間も停止ボタン・Escが効く) |
| キャプチャーの開閉 | 開始時に開き、停止時に閉じる(停止中に取り込みスレッドを動かし続けないため) |
| 解像度の確認 | 設定値ではなく、実際に取得した最初のフレームの大きさで確認する |
| フレーム取得の失敗 | 最新フレームが2秒以上更新されていない場合も「取得できない」とみなす。再試行(1秒おきに3回)の値は固定 |
| FOURCC | `config.json` の `capture.fourcc` に `"MJPG"` などを書くと設定する(初期値は空=設定しない)。1080p60 が出ない機器向け |
| Escキーの監視 | 監視が動いていない(pynput が使えないなど)ときは開始しない |
| 監視の間隔 | 読み取りを始めてから次の読み取りを始めるまでの間隔(OCRにかかった時間を含む) |
| 数値の読み取りと反応待ち | 同じスレッドで、まず数値を読み取り、そのあと反応待ち時間の残りを待つ。確定が遅れた場合は確定後すぐに操作する(FR-30/32 を満たす) |
| 数値の確定の打ち切り | FR-31(5) の打ち切りを実装した。例:`["12.5","abc","12.5"]` の時点で避難動作へ |
| クリック座標 | 余白を取れない軸だけ中心座標を使う(幅だけ足りない場合など) |
| マウスの軌跡 | 3次ベジェ曲線。制御点は進行方向に垂直にずらす(最大で距離の25%、200ピクセルまで)。ease-in-out は余弦カーブ |
| クリック | 移動後、その座標で `pyautogui.click` を1回 |
| OCRの文字の連結 | 左端のX座標の順に、区切り文字なしで連結する(「1,」「250」→「1,250」) |
| OCRの方向分類 | 使わない(`use_cls=False`)。1行の横書きのため |
| 前処理の余白 | 切り出した画像の縁の色の中央値で10ピクセル加える |
| OCRの準備 | 起動直後に別スレッドで RapidOCR を1回だけ作る(GUIをすぐ表示するため)。開始時は準備が終わるのを待つ |
| 空の待機表示 | 待機表示の文字が空の設定は保存・開始できない(空の読み取りを WAITING と誤判定しないため) |
| キーワードと待機表示 | キーワードが待機表示と同じルールは保存できない |
| 数値の形式 | 利用者の要望により、ルールごとではなく全体で1つ(`config.json` の `number_format`)とし、メインウィンドウに置いた。動作中の切り替えは、次の数値の読み取りから反映する |
| キャプチャーを開く方式 | DirectShow で開けない場合は Media Foundation、既定の方式の順に試す。機器番号は「詳細」タブで変更できる |
| 開始時の検証 | 8.2節に加えて、全ルールに 8.1節の検証(キーワードの重複・必要な範囲)も行う |

### GUI

| 項目 | 判断 |
|---|---|
| 設定ウィンドウを開いている間 | 「開始」は押せない(保存していない設定で動かないため) |
| 設定の保存 | 「保存」で反映・書き込み。ウィンドウは開いたまま。「閉じる」は保存していない変更を捨てる |
| 動作の記録 | 読み取り専用の `Text`(折り返しあり)。行数の上限は1件=1行で数える |
| 詳細タブ | 仕様の項目に加え、OCRの最小の高さ・クリックの余白・記録の最大行数も変更できる(12章「数値の項目はすべてGUIで変更できる」に合わせた) |
| ルール名 | 空のまま保存するとキーワードを使う |
| パターンの切り替え | 表示していない範囲の項目は、保存時に未設定にする |
| 避難先 | 選んでいたルールが削除された、またはパターンBに変わった場合は「(未設定)」に戻す |
| 退避エリアの重なり警告 | キーワード範囲と、パターンBのルールの数値範囲を対象にする |
| 読み取りテスト | 設定ウィンドウでまだ保存していない OCR の設定(`ocr_use_det` など)で読み取る。結果は記録にも残す。キーワード範囲のテストでは、待機表示/一致したルール/不一致も表示する |
| 範囲設定のオーバーレイ | 5ピクセル未満の範囲では「小さすぎます」と表示してもう一度ドラッグさせる |
| 範囲の表示 | 3秒で自動的に閉じる。クリックすると早く閉じる |
| ルール編集ダイアログ | 開いている間は設定ウィンドウを操作できない(モーダル) |
